## The project

Sample project: a small Shopify store doing steady orders but run from memory — listings inconsistent, stock tracked by feeling, inbox answered when someone remembers. **This is a concept project. No client, no store, no numbers.**

## The flow I would own

"I'll manage your Shopify order flow and customer inbox" — one owner, daily rhythm:

1. **Morning — orders.** New orders checked, packed list prepared, tracking numbers updated. Anything stuck (unpaid, address unclear) flagged before noon.
2. **Midday — inbox.** Shipping questions, returns, damaged items — answered from reply templates, personalized per customer. Response window under 12 hours.
3. **Weekly — listings & stock.** New SKUs listed from the template (title, variants, tags, SEO description). Inventory synced between Shopify and the tracker. Dead SKUs flagged.

## Listing template

Every product gets the same treatment: clear title with keyword, consistent photos (same framing, same light), variants that make sense, tags for filtering, and a description written for buyers, not algorithms. AI drafts the first version from the spec sheet; a human checks tone and accuracy before publish.

## Inbox templates

Five situations cover 90% of messages: where is my order, returns, damaged item, refund request, and product questions. Each has a template with blanks for name, order number, and resolution — fast without sounding robotic.

## AI-assisted, human-checked

ChatGPT drafts listings and reply first versions plus a prompt library per store voice. Zapier moves new orders into the tracker automatically. Nothing customer-facing goes out without a human read.

## What this sample shows

A store run as a system instead of memory: listings consistent, stock visible, inbox answered, weekly numbers on one page. Planning work is real; numbers are not claimed.
