- Writes in casual Indonesian slang (e.g. "gue", "dong", "lo") and expects replies in the same register. Confidence: 0.75
- Asks to be "grilled" — wants to be challenged with direct, tough counter-questions before any deliverable is produced, rather than getting agreeable generic advice. Confidence: 0.7
- Wants recommendations grounded in real market data (e.g. actual Upwork demand/rate data with cited sources) instead of opinion-based generic guidance. Confidence: 0.65
- Points the agent at existing local artifacts (prior project directories, reference PDFs) and expects it to inspect them before advising, rather than starting from scratch or guessing. Confidence: 0.6
- Self-identifies as a fast learner and is willing to pick up missing skills (e.g. API integration, automation) on the job; prefers being pointed at advanced tooling and approaches rather than having recommendations capped at their current skill level. Confidence: 0.5
- Wants design work handled explicitly before implementation — asks the agent to pause building and run the `/design` skill first for UI/website work, and wants to see a rendered visual preview (something openable in a browser, not just a written spec) to judge the look before it gets implemented. Confidence: 0.65
- Works on Windows with projects stored under local drive paths (e.g. `D:\PROJEK\...`, `D:\skill_coba\...`); expects the agent to read those paths directly. Confidence: 0.55
- Opens and judges the actual running preview himself, so a green build/check script is not accepted as proof the deliverable works — he expects the served pages to be verified end-to-end (e.g. stylesheet actually loading) and defects like "preview nya kok tanpa css?" to be root-caused and fixed. Confidence: 0.6
- Dislikes being interrupted by tool/command approval prompts and prefers a low-friction agent setup (e.g. switching `permissions.defaultMode` to `auto-accept` at user scope). Confidence: 0.5
- Expects visual assets to be pulled from his own existing source material (the reference PDF, the previous project's files) rather than generated from scratch or invented; asked for the site's images to come "dari pdf saja sama web sebelumnya". Confidence: 0.6
- Expects portfolio previews to use platform-native layouts — Instagram projects as square 3x3 grids, TikTok projects as full vertical portrait feeds — and flags truncated previews or oversized covers as revisions, often naming an existing correct card as the size reference to match. Confidence: 0.75
